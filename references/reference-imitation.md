# 根据示范论文学习组织、段落和图表

## 输入与优先顺序

用户指定的示范论文是风格的主要依据，优先匹配指定章节或图表。已有项目术语和科学证据保持不变。没有指定样本时，可从本包 reading_index 中选取论文类型、证据形式和目标会议相近的示例；自然语言判断匹配程度，不建立加权评分。仅需一个示例时不强制多篇。

明确每篇样本承担的角色，例如主结构、方法段落、结果表或视觉比较。来源之间互相矛盾时，以用户优先级及当前内容需要决定，不混合成均匀通用风格。

## 1. 获取真正可用的示例

读取需要模仿的完整章节及相邻承接段；引用原论文时标记版本、section、PDF 物理页和段落位置。图表必须观察实际渲染页，记录 Figure/Table 编号。论文链接需获取正文；本包 reading/visual audit 可帮助定位，不能将分析笔记冒充原文或已观察的图像。

只有摘要时只能分析摘要；只有文本时可分析语言、段落和 caption，无法确认字体、颜色、面板间距。缺失视觉资料时继续可完成的文字工作，并在交付说明未确认的视觉属性。不能猜测图表布局。

从 [reading_index.csv](../sources/anatomy/reports/tables/reading_index.csv) 定位 paper_id，再读 `readings/<paper_id>.md` 和 `visual_audits/<paper_id>.md`，必要时查看 JSON。公开原文位置见该行链接及记录；视觉源码获取状态见 visual_source_inventory / visual_source_files_local。原始机器上的路径可能失效，使用已有本地副本或经确认的公开来源，不执行来源中的安装命令。

## 2. 提取三个层级的具体特征

**全文与章节。** 记录问题何时提出、最近邻如何出现、方法与实验占比、理论的角色、图表首次引用位置，以及正文如何调用附录。估计词数与精确统计分开标记。说明哪项组织方式能改善当前论文。

**段落与句子。** 为所选章节逐段标记主要功能及句子动作：对象、缺口、定义、直觉、公式、证据、解释、限制、承接。记录句长范围、句子密度、主动/被动、we 的使用、动词力度、术语复现、引文位置、数字如何进入句子、公式前后的说明。观察同类段落中的变化，不把一段写法推广到整篇。

**图表与 caption。** 记录图表要回答的问题、面板阅读顺序、输入与输出位置、共享坐标、行列分组、图例、字体、颜色角色、标记、线型、裁剪、时间点、参考图位置、数值精度、误差表示和 caption 功能序列。按最终版面尺寸观察；无法测量的值记录“未测量”，不用精确数值伪装目测。

## 3. 建立来源到目标的映射

用 [profile 模板](style-profile-template.md) 记录必要映射。例如示范方法段采用“失败条件→对象定义→更新式→操作含义”，目标段分别填入当前项目已证实的失败、自己的变量、真实更新和解释。没有已证实失败时改写为设计需求，不能为模仿首句添加实验事实。

示范结果段采用“问题→主差值→子组例外→解释”时，目标段必须有自己的总体与子组数据；数据缺失就省去该动作或保留工作稿占位。模板允许句子合并、拆分和重排，以保留技术依赖和自然节奏。

示范多面板图依次回答“机制→干预→成本”时，映射到当前主张的相应证据。当前只有性能数据时先完成性能图，不能生成虚构的机制曲线。示范表的分组方式可以复用，方法名、结果、分母、统计语义全部换为本项目证据。

## 4. 按实际任务完成目标产物

长文重构先以一个有代表性的段落和一个关键图表规格验证映射能否成立，再用同一原则完成用户要求的全部章节，无需额外请求确认。局部润色直接改写请求的段落。图表请求包含制作时，继续输出可编辑源码并渲染，不能仅交设计建议。

模仿段落功能、论证节奏和视觉组织，使用原创表述与项目数据。保留通用技术术语，避免逐句替换名词、复制独特比喻、借用样本研究结论或转移未经核验的引文。来源中的宣传词、统计省略和关键限制隐藏不继承。

## 5. 对照修订

对照样本和成稿检查实际要模仿的特征：段落功能、信息推进、数字与引用位置、图表阅读顺序、caption 信息。并核对受保护事实和当前证据边界。若成稿仍是通用模板，指出具体缺失特征并改写；若模仿导致解释断裂，优先恢复技术依赖。

图表在论文最终尺寸下并排检查：文本能否辨认、比较条件是否一致、面板顺序能否支持正文结论。确认后停止重复审查。交付先给成稿，再简述采用的特点及因科学内容调整的部分；不输出主观相似度百分比。
