# Style · 示例仿写

## 用途

学习用户示范论文的组织结构、学术语言、段落推进、图表布局与 caption，并用当前项目事实完成新稿。支持整篇、指定章节、单段、图表或 caption。

## 执行

完整阅读 [Reference imitation](reference-imitation.md)，并按当前范围使用 [Style profile](style-profile-template.md)。

1. 定位并读取实际范文；图表需观察渲染结果。区分真实原文、分析记录、摘要与视觉资料。
2. 提取章节、段落、句子和图表中与请求相关的特征，记录 section/页码/图表编号。
3. 建立“来源功能→当前证据→目标段落/面板”的映射。缺少对应证据时调整功能或标注缺项。
4. 使用原创表述、当前变量、实际数据与真实统计口径完成产物。制作请求应交付可编辑图表源码和渲染结果。
5. 对照检查功能顺序、句式节奏、术语、视觉组织和事实保持情况，修正具体差异后完成全部请求。

## 输出

成稿或图表优先；简述采用的示例特点及必要调整。不能用主观相似度分数替代改写，不能从范文复制研究数字、引用或未经本项目验证的结论。
