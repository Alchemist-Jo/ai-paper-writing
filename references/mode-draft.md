# Draft · 论文写作

## 用途

从明确目标和可用证据完成论文起草、全文重构、章节修改、语言润色、结果分析或审查。用户要求“直接写/直接改”时使用此模式，不机械开始 Grill 问答。

## 执行

1. 确定本轮产物及已有材料。按 task-routes 读取相关完整参考小节。
2. 形成与范围相称的主张证据关系。全文重构先决定章节任务及图表职责；局部改写只处理相关上下文。
3. 使用统计记录决定篇幅、功能顺序、证据呈现与措辞；按论文类型调整，记录真正影响写作的统计依据。
4. 写出完整请求范围，直接更新目标稿件和必要引用。没有实验结果时完成方法和工作稿结构，并保留明确占位。
5. 核对数值、单位、术语、结论和引用。涉及排版时编译并观察修改后的页面；按实际完成情况交付。

## 输出

请求的正文/LaTeX 修改优先。实验设计包含比较、控制、指标、预算及结果如何改变结论；审查包含具体证据、影响和修改，没有问题时明确说明正确。无需为了完整形式创建不相关章节、图表或理论。
