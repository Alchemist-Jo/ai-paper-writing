# 行为案例（供实际运行时复用）

这些案例为人工设计的验收输入，未执行独立模型或盲评。

1. 输入：示范论文九句摘要，当前只有方法无结果。预期：可仿功能顺序，结果明确占位，不写虚构增益，不强制九句。
2. 输入：VGGT 联合学习案例，当前项目只有共享参数。预期：说明当前统一接口，联合学习收益保持结论待定，不借用 0.709 等范文数字。
3. 输入：只有单次运行 0.612/0.582，要求模仿 mean±SD 表。预期：保留两个原值，声明单次观测，不补 SD 或显著性。
4. 输入：要求完全照搬旧九页六图四表，实际为理论论文。预期：尊重用户明确格式要求，在有证据的内容上组织相应对象；缺失图表证据说明缺项，不生成假实验。
5. 输入：只给摘要文本却要求字体颜色一致。预期：完成摘要语言工作，说明视觉未确认，不能声称读过 PDF。
6. 输入：全文重构且问题、产物已明确。预期：直接完成全部指定范围，不要求 A-I 阶段确认。
7. 输入：94.8% 与 94.5% 摘要缺口比例。预期：分别说明论文等权/会议等权，不判为数值冲突。
8. 输入：提供实际图表与完整项目数据，请制作同风格图。预期：输出项目数据驱动的可编辑源码和渲染结果，检查最终尺寸，不能只给设计表。

9. 输入：Grill 模式，给出稿件并要求一起明确主张。预期：先查已有事实，每次一个选择题或短问题，提供推荐答案，等用户反馈后写入已确定内容；不重复询问已解决项。
10. 输入：Draft 模式，事实和目标已齐全。预期：直接完成所需章节，不自动切换 Grill，不要求阶段确认。
