# Wording Rules

These rules apply to all manuscript English that any paper skill writes or edits. They never apply to quoted titles, citation keys or code.

## Contents

- Punctuation and symbols
- Banned openers
- Replaced words
- Restricted words
- Phrases that carry no information
- Patterns that read as generated

## Punctuation and symbols

- No em dash (—) in prose. Use a comma, a colon or a new sentence. En dashes in number ranges stay.
- No `$>$` or `$<$` in prose. Write "greater than" or "less than". Mathematical expressions keep their symbols.
- Few parenthetical insertions. Move a condition into the sentence, or into the next sentence.

## Banned openers

Never start a sentence with:

- It is worth noting
- Notably
- Specifically
- In particular
- In recent years
- With the rapid development of

"Furthermore" and "Moreover" never appear in consecutive sentences. A connective that only signals "one more point" is usually deleted.

## Replaced words

| Word | Replacement |
| --- | --- |
| leverage, utilize | use |
| delve into | study, examine |
| pivotal, crucial (as praise) | the specific role, or delete |
| showcase | show |
| underscore | show, or delete |
| intricate | name the specific complexity |
| plays a crucial role in | state what it does |
| has attracted increasing attention | state who uses it and why, or delete |
| a myriad of, a plethora of | many, or the number |
| seamlessly | delete, or state the integration property |
| paradigm shift, groundbreaking, revolutionary | delete |

## Restricted words

| Word | Allowed use |
| --- | --- |
| significant, significantly | only with a statistical test that was run |
| robust | only with the perturbation it survives named |
| novel | only for the paper's own contribution, when verified |
| first | only when verified and essential |
| state of the art | only with the comparison that establishes it |
| reveal | allowed |
| comprehensive, extensive | only with what the coverage includes |

## Phrases that carry no information

Delete or replace with the specific content:

- sentence-final "highlighting the importance of ...", "underscoring ...", "demonstrating the effectiveness of ..."
- "In this paper, we" at the start of every paragraph
- "It is important to note that"
- "As we all know", "It goes without saying"
- "a wide range of applications" without the applications
- "To address these limitations" without the observation the proposal builds on

## Patterns that read as generated

Check every edited paragraph for these patterns.

1. **Rigid enumeration.** "First, ... Second, ... Third, ..." over points that are not ordered. Join them into a paragraph with real relations.
2. **Smooth transition over a gap.** A transition sentence that hides a missing logical step. Supply the step or remove the transition.
3. **Restatement.** The same point said twice in different words. Keep the precise version.
4. **Symmetric contrast.** "not X but Y", "rather than X, Y" used as rhythm. State Y directly.
5. **Balanced non-commitment.** A claim stated and then softened in the next sentence. Keep the version the evidence supports.
6. **Metaphor and inflated abstraction.** "a lens", "a tapestry", "unlocks", "paves the way". Name the operation or the result.
7. **Uniform sentence length.** A paragraph of sentences of nearly equal length. Vary length by function.
8. **Shifting reader.** One sentence written for experts, the next explaining basics. Hold one reader, a peer in the broader field.
